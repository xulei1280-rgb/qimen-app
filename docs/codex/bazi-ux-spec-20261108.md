#### B. 新规则契约：先结算实际作用，再按本盘主线判方向
以下是**本项目新增的工程裁决政策**，依据“格局成败救应、病药、先实际生克再喜忌”的子平方法；优先级/平局政策不是古籍通用公式。沿用项目已有规则来源和术语；不得杜撰古籍原文、页码或声称这是唯一传统规则。每条新结论须留 ruleId、比较对象、作用者/受作用者、before/after 事实、采用/排除原因，尽量复用现有 evidence/review 结构。

**Y0 输入/比较边界**（先执行）：无效四柱、运干支、年干支不匹配仍为 input-error；第一步大运无前运仍 unavailable，不纳入“规则覆盖不足”。natal=原局→原局+本运；previous=原局+前运→原局+本运；annual=原局→原局+本运+年；increment=原局+本运→原局+本运+年。不得拿流年单独喜忌冒充 annual；不得用 natal 方向直接填 previous/increment。

**Y1 有效性与去重**（所有层先执行）：
1. 从已算出的 interactions/profiles/root evidence/active steps 取真实生、克、泄、扶、合绊、合化、冲；先采用既有 active/usable/transform 裁决，不能凭干支字面另宣布成化。已合化者按已确认变气取作用，不再同时按原五行计一遍。
2. 根、天干、药链、病点用 cause/actor/target 去重；同一“印生身”不得再按主用、佐用、解病重复加票。不是证据条数投票，不新增运势总分、不借原局结构档位裁方向。
3. 藏干不一概当透干；`potential/conditional` 不变为 effective。某条药路受制不能反推“药已完全消失”；单个根受冲也不等于日主完全无根。对只剩 null 的旧任务，可独立输出另一条已验真的作用方向，但不把该 null 任务改写成完成。
4. 前后比较须有物理作用差异（作用者、可用根、有效药路、病点/成败要素改变）。单纯数值跨阈值无独立方向。

**Y2 最高层：原局已成立特殊格的顺逆势**：有真实资格时，以已验真目标气势和可用出口为参照。增强有效顺势/恢复出口为 positive；实质逆制目标或切断必要出口为 negative；逆势必须有可用作用者与路径，不能由资格开关直接判坏。特殊路线转移时，比较同一个“所用气势/出口/承载需求”，不能按新旧格名排名。只有特殊格线索、无原局资格的盘，不进入本层。

**Y3 关键层：主病药、用相神与必要根气（同层结算）**：
- “主病”不新增严重度排名：原局 `patternDisease.items` 中未解/部分化解的各 family，以及原主格 issues/conflicts 有对应 source 的病点，均为本层同权锚；已解病点保留为防止复发的锚。按 family+source 匹配前后，不按数组顺序挑胜者。土厚埋金等五行病象从原局已确认 `elementPhenomena` 取对应项，不伪称它必在 disease.items。主格必要链只取原局已确认 qualification/checks/interactionFlow 的对应参与者。
- 固定原局的这些病/必要链作为比较锚；读取 before/after 对应病点的 `status`（未解/部分化解/已解）、`bestRank`、`medicines[].rank/steps[].active` 及真正 active 的药路（字段定义见 `patternDiseaseAssessment:2334–2408`）。rank提升仅在真实作用链改变时生效；不修改此原局函数。病压得到实际制化、原必要用神/相神恢复可用、日主必要承载根恢复 → positive；原有效救应被制住、病压增加且承接未增、必要用相神/唯一承载根失用 → negative。未解变部分缓解可判“缓解”，不能说全病已解。
- 财多身弱/身不任财：有效印比与承财根增加先判扶身助力；新增财负荷且有效承载未增判牵制，不能直接“见财吉”。比劫扶身不自动记争财；争财须既有实际夺财证据。
- 杀重身轻：核同一杀压下印化杀生身、食伤制杀等有效承接；同一需求有替代药路接上不按旧路消失直接判坏。仅官杀出现不算混杂加重；用实际去留/制化结果。
- 伤官见官：实际伤官克官且无有效印制伤/财通关为牵制；护官/通关链接通或增强为助力，不以见印即配印成格。
- 土厚埋金：金根/有效润泄改善壅滞为助力；火生土或土再壅身且无新增有效出口为牵制。保留原印已化杀的功能，不能把同一印土说成全无益处。
- 用神/相神/破格之神只从原局已确认的角色与链提取（这里的“格局用神”不等于页面“主用五行”）。生扶必要用相神或制住实际破格者为助力；损用伤相或扶起有效破格者为牵制。没有结构化角色时不得按格名字典臆定演员；改走已知病药、喜用层。
- 冲合刑害落在日主根或月令：复用已有根 usable/bound/transformed/attacks 与月令角色，不改月令季节身份。冲去必要根/合绊关键用相为牵制；解除原绊、保留替代根或破坏实际忌神为助力/救应。刑害破仅关系名不算失根；合不一概吉、冲不一概凶。得令仍不等于免除实际受制。

**Y4 常规结构层**：无 Y2/Y3 的决定性差异，采用已确认的格局任务变化、一般根气/承泄/生扶变化。两侧不同路线先投影到同一需求（承财、承杀、护官、食伤出口），替代路径成立就按需求前后比较。不得按“杀印高于财格”等人为排序。无关键承载短缺且偏强，实际食伤出口增强可记助力；身弱且未获承接，新增泄耗不得同判助力。刃禄结构补查可达食伤出口、财生官杀的真实承接，不要求只有官杀制刃才能存在方向；不回写原局格局结论。

**Y5 既有主用/佐用/忌五行层（补覆盖，不重判原局）**：
- 固定 `analysis.useful` 的 primaryUse/secondaryUse/avoid、decision、roles、arbitration；不把 routeDependent 并入默认喜忌，不把主用空视为缺算，佐用不升级。
- 运/年干、支本气及真正可用藏干对主用/佐用/忌的具体生克：同气增援或生主用/佐用，且对方实际可接、生扶路径未被制化 → 助力；克制/合绊其有效作用或增加已列忌的有效作用 → 牵制；克制实际忌神、泄其过量并接到可用出口 → 助力；生忌/使既有药受阻 → 牵制。不得把“喜用五行被泄”一律当坏：有实际顺生出口就按所成的链判；不得把所有“克忌”都当救应。
- 生克链的每一步均需既有 active 证据或复用既有具体可达性判据；不能任意把五行环上的远程生克当实际作用。盖头/截脚按已算通关/他根保留哪些作用来结算，不一概判整柱凶。
- 主用层内存在可用正负作用按冲突规则处理；主用无作用后再取佐用/忌。佐用有前提：仅使用本时段已验真的条件项；前提不满足不计为助力，转查实际受阻/其他已知路径。avoid 空不推出“全吉/全平”。
- 若只在同气可用根数量上有差异，须用原局已确认的角色（扶身所需/印土过量/需泄秀等）定正负；角色不明不靠根数强判。增加根和根的恢复归同因，不重复记。

**Y6 调候辅助层**：只用原局已确认寒暖燥湿病与本时段实际调节链；缓解该偏性为助力、加重且无有效调节为牵制。已有“过量/反作用”必须先结算，不用季节口诀给每盘重新发一套调候喜忌。调候本已是原局关键病/主用时归 Y3/Y5，不在这里降级或重复。

**Y7 确定性优先与平局政策**：
1. Y1 先结算救应和同因去重；按 Y2 → Y3 → Y4 → Y5主用 → Y5佐用/忌 → Y6，取第一个有有效方向变化的层为主判。已确认的主病权重先于一般五行喜忌；特别是“印有化杀功能但土已壅身”，不能用低层喜印覆盖主病加重。
2. 同层同一因果链，取救应后的净作用；不把“压力出现+其有效化解”当两个独立利弊。不同独立作用一正一负 → `mixed`（利弊并见），不相加抵成 neutral，不用证据多的一边胜。最高有效层只有正/负就给 positive/negative，较低层反向作用列一条具体次要牵制/救应，不消失。
3. 真正无有效变化、且同需求/同演员关键状态已逐项核验延续 → `neutral`（主线延续）。既有未知前后完全同因同状态、不影响任何已确认作用方向时，保留审计但不再一票否决；不得仅因字符串相同或证据为空就判 neutral。
4. 已有 determined 结果默认沿用。若新增高优先规则证明旧结果遗漏关键实际作用，必须在回归表逐条写旧/新方向、ruleId、证据和翻转理由；无解释不得翻转。旧 conditional 的单边 tendency 也要逐条检查是否被新规则反向，并说明。
5. 新规则直接在岁运层产出四向之一、规则版本及具体证据；沿用 determined 表示“本规则完成裁决”，不冒充所有旧 task.state 都已解。保留未解 task 和具体限制到审计/依据；不要清空 uncertainty 或仅将所有 conditional 的 assessment 改名。UI 不得自行推断。

**规则表**：
| 格名/状态/强弱 | 病象与救应 | 说明应围绕的具体内容 |
|---|---|---|
| 财格已破/待成、身弱 | 财多身弱，无有效印比 | 主问题承财不足，不宣称经营守财能力 |

**改哪里**：`renderBazi`、`switchBaziView`、`renderBasicInfo`、`renderStructure`、`patternConclusionText`、深层detail组织。
**结构**：
