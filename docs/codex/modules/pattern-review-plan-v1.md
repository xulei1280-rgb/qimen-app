## 3. 统一的判断合同

### 3.1 证据分层，而非书名排队

1. 出生资料与历法输入是事实层；本轮不由真人反馈改这些事实。
2. 月令、根透、合冲状态及具体十神对象是可复算的模型证据。
3. 格局、病药、喜忌与层次是本项目所选框架的推论；不能冒充可测的物理能量。
4. 生克路线与现实的收入、健康、性格之间不是已经验证的因果；不得自动作具体人生断言。

来源规则沿用 [`pattern-sources/rule-crosswalk.md`](pattern-sources/rule-crosswalk.md)：
原典、原注、徐乐吾／任铁樵等评注分开署名；古籍条件与工程阈值分开记录。
不因资料更古老、更新、更有名或数量更多就自动获得最高优先级。

### 3.2 取用不是固定“病药永远优先”

先确认当前盘是否存在实质病点、可维护的成格功能、承载需求或明确的气候偏性，再比较
对应路线。通关可以承担主要病药功能，不按“扶抑／调候／病药／通关”的名称固定排队。

采用或否决必须指向：所保功能、实际作用对象、损益证据、替代路径及撤销条件。
不能因一个诊断标签自己产生病点，再用这个病点循环证明自己的优先级。
未被选为主路线的局部收益仍须保留；风险只是可能发生时，不能写成已经致害。

先分析具体天干、藏干、十神和所处位置，再归纳五行。甲、乙等同属一个五行，不意味着
它们在每条链中可无条件互换；严格格未成也不等于局部功能全无或该五行必忌。
根气另按可用同五行证据核对，可有阴阳不同的同气根；根气支持不改变实际作用者的十神身份，
也不把一份根力重复计入原始能量／计数。

原局已有功能、维持该功能、补足未成条件、再增加同五行、岁运触发分别记录。
不能从“某药原局有效”直接推出“继续增加越多越好”。证据不能判出唯一胜者时，保留
具体条件差异，不加新权重、拼五行并集或补个案例外硬选一个答案。

### 3.3 输出层级固定

- 主喜／主用：满足当前默认采用条件的主要取舍。
- 佐用：次级且有据的辅助，不与主喜视觉平级；没有就不写。
- 条件用：明确写有利面、制约与成立条件；只有实际双面证据才写“喜中带忌”。
- 忌：有相应有效制约依据时直接写“忌”，不用统一的“慎增”替代。
- 取法差异：有独立出处但未被默认采用的解释，留在现有折叠依据中，不并入默认喜忌。

“伤官格忌无救的伤官见官”等通则必须与本盘救应结果分开，不能把通则当成本盘已无救。
主要结论短、理由突出；来源、各路线条件和反证放在已有依据展开区，不增路线选择器。

## 5. 测试不能变成答案生成器

依据 [`pattern-confirmation-bias-postmortem.md`](pattern-confirmation-bias-postmortem.md)：

1. 先给来源语境和成立／反证条件，再写最小成立例、单条件反例及组合反例。
2. 理论命盘检查干支阴阳、五虎遁、五鼠遁合法性。纯图运算单元须明标不是出生盘。
3. 从程序里筛出的“严格正例”只能作候选，必须独立核对条件；不能用程序输出证明程序正确。
4. 不固定真人的五行喜忌、格名、档位、分数或人生结果。已知案例只验证明确错误不再复发。
5. 修改旧断言必须写原因：旧盘不合法、必要条件不成立、旧语义错误，或新实现有缺陷。
   不能把所有红测都叫过期预期，也不能删掉有价值的反例来变绿。
6. 720 项零运柱合法保留集、240 项取用网格、18 历法基线分别有职责；通过一种不代表其他种完成。
7. 保留集用于一致性检查，不是外部现实真值或预测准确率。局部段通过不能代替完整页面检查。
