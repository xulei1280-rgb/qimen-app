# 取用仲裁 v2：作用与采用分账（PAT-214）

## 本轮边界

保留现有主盘、评分、历法、模型及 UI 结构。原始 main 备份与 v1 候选快照均不覆盖。
本轮不预设任何真人必须喜木金或金水，不使用财务经历标定答案。

## 规则冻结

- `ZP-USE-06`：同一框架的局部可达作用必须进入逐元素收益账，即使没有被选为默认主线；其风险同样入账。不同分月取法只进 reference 账，不混成默认喜用并集。
- `ZP-USE-07`：风险分 effective / potential。缺少采用条件、保守成格闸门未过、可能生杀、需要承接，只能是 potential，不能单独推出忌。已验真气势病象、明确守格禁项及未解病点的有效致害链可构成 effective；判忌必须说明舍弃正向作用的具体依据。
- `ZP-USE-08`：通关可以是病药的一种。对主要病点有对应局部作用的候选，比一般性帮扶优先列入条件取用；不把所有通关固定排第一，不由 weak 标签消除其收益。作用可达不等于已完成救应或完整成格。
- `ZP-USE-09`：当前方案存在局部收益兼风险，保留有条件可用；未选取法不等于忌。只有潜在风险时称“有条件”，两面已有有效证据时称“喜中带忌”。不同完整取法的差异单列 routeDependent，不默认加入 use 或 avoid。

来源层次：

- 《子平真诠·论相神紧要》按关键救应对全局的功能论轻重；“相”不代表低级佐用。原文与徐乐吾注分开。
- 《滴天髓阐微·通关》任铁樵评注论作用接续与阻隔；不能仅见相生关系即认已通关得用。
- 《子平真诠·论伤官》完整生财成格另有条件；不得把贵格门槛搬成所有局部收益存在的条件。
- 《穷通宝鉴》六月丙火壬庚取法保持独立，并记录原节己土混壬等限制，不外推金水年必发财。

## 输出契约

`decision.conclusion` 保留 primary / secondary / conditional / avoid，新增 routeDependent。
`elements` 每项增加 benefitEntries（local / proposed / reference）与 riskEntries（effective / potential）。
路线增加 priority 与 assessment；条件取用从对症作用到一般帮扶排序，不增设用户路线选择。
旧字段仍为 canonical 派生，不在 UI 或 AI 各算一套。严格特殊格维持独立语境。

用神总论默认显示重点结论、一句理由，有取法差异则单列；全部作用链、条件、出处置于原生折叠内。
AI 和导出使用完整纯文本，不因页面折叠丢失判断依据，不改写历史问答。

## 验收

合法理论成立盘、单条件反例及已有守格／病象忌项必须保留；actual 收益不丢、potential 不直接判忌、
对症通关不被一般扶身压后、分月不并集、所有出口同源。桌面／手机检验折叠、键盘与溢出。
验证规则实现与解释一致性，不宣称现实预测准确率。
