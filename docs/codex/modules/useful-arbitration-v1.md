# 旺衰与取用仲裁 v1（PAT-214）

## 边界与冻结规则

本次改动不改变历法、评分权重、五档边界或模型配置；不以真人经历规定喜用答案。
沿用月令格局主线，调候、扶抑、病药是有条件的校正，不是可任意取并集的五行清单。
规则实现正确与现实预测准确率是不同的验收目标。

| 规则 | 来源与用途 | 必要证据／反证 | 输出边界 |
| --- | --- | --- | --- |
| ZP-SX-01 | 《滴天髓阐微》衰旺、中和；现有人元分野表 | 节后日数、司令、有效根、透干印比、受损；时间缺失须明示 | 固定比例扶身指数保持原公式，司令独立参与承载的条件证据，不能伪装成精确能量或任意加分 |
| ZP-CAP-02 | 旺衰服务任用、食伤财官各有职责 | 任财、承泄、任官杀分别检查支持与负荷；同类季令不能抵消根损和所有负荷 | 严格成格仍用保守工程入口；局部作用不被一个 bool 一票否决 |
| ZP-USE-01 | 《子平真诠》成败救应、伤官篇；《滴天髓阐微》通关 | 印制伤须伤印作用对象；财通关须食伤、财、官实际存在与位置可达，另记坏印、生杀及承载限制 | 伤官见官名称不直接推出印财并集；局部可用不等于伤官配印或生财成格 |
| ZP-USE-02 | 月令立格、相神 | 已验真的主格作用链，不取诊断字符串；未成格只能参考 | 无直接未解病点时先守已成格；有病须有匹配的药路才进入病药优先 |
| ZP-USE-03 | 《滴天髓阐微》寒暖燥湿；现有 seasonTune | 季节提示与实际偏枯分开，气候偏枯和格局冲突均保留 | 极端偏枯可优先，但不静默覆盖结构；非偏枯季节提示不自动列喜忌 |
| ZP-USE-04 | 《穷通宝鉴》六月丙火 | 丙日未月；按壬、庚具体根透记录，不代换成所有水金；受生杀、承载等限制 | 作为独立分月参考解释金水来源，不自动覆盖默认取用或断发财 |
| ZP-USE-05 | 统一取舍工程契约 | 每个候选五行独立汇总利益、风险、缺失条件；一视同仁 | 有利益兼风险才标条件用／喜中带忌；备用路线不自动变成佐用；不预设主喜或忌神数量 |

`1.4` 根力、扶身指数 `30/42/55/65`、气候比例、距离可达等均是可复算的项目参数，
不是古籍提供的物理量。相同四柱在不同月内时间可以有不同司令证据；没有出生日期的四柱全集
只能审计不含月内深浅的结构，不能冒充时间敏感性验证。

## 单一数据契约

`useful.decision` 保存版本、优先层、路线、结论及逐元素取舍；原 `primaryUse / secondaryUse /
conditionalUse / use / avoid` 是兼容派生字段。页面摘要、折叠说明、AI、导出读取同一对象。
路线状态为 selected / conditional / reference / rejected；路线 conditional 不等于推荐佐用。
原局结论不随某年经历改写；大运四面板复用 evaluateLuckOutlook 的独立时域结论。

## 验收

- 单条件变化、缺失时间、同四柱不同司令、局部作用与成格分离、五行利益风险一致性。
- 严格特殊格维持独立语境；默认取用与其校验层不得互相污染。
- 页面结构、折叠、AI 当前事实、原历史不改写，桌面与手机均核对。
- 18 个历法基准不变；理论时间网格重建另版，不改活动评分回滚点。
- 所有通过仅证明冻结规则和消费端一致性，不声称已经验证现实预测准确率。
